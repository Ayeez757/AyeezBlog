# 生产运行基线（迁移到 Compose 之前）

本快照用于记录迁移前线上环境的实际运行拓扑。

## 容器

- `ayeezblog-backend`
  - 镜像：`ayeezblog:latest`
  - 端口：`8080:8080`
  - 网络：`ayeez`
- `nginx`
  - 镜像：`nginx:1.29.5`
  - 端口：`80:80`、`443:443`
  - 卷：
    - `html` -> `/usr/share/nginx/html`
    - `config` -> `/etc/nginx`
  - 网络：`ayeez`
- `mysql`
  - 镜像：`mysql:9.6.0`
  - 端口：`3306:3306`
  - 数据卷：
    - `00bf7a5c3317bc4d650e5815dbfd74b4866867e2d46cba4e75958b8434e28e08` -> `/var/lib/mysql`
  - 网络：`ayeez`、`bridge`

## 网络

- 外部网络名：`ayeez`
- 子网：`172.18.0.0/16`

## 迁移守护规则

- 不要执行 `docker compose down -v`。
- 不要删除 `html`、`config` 和 MySQL 数据卷。
- 保持容器名不变（`mysql`、`nginx`、`ayeezblog-backend`）。
- 后端运行 profile 保持 `dev`。
